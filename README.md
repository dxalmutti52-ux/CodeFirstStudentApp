A simple Entity Framework Code‑First console application that creates a Student database and inserts one student record.

 Project Overview
This project demonstrates the basic use of Entity Framework 6 (Code‑First approach) inside a Console App (.NET Framework).
When the application runs, EF automatically:

Creates a database named StudentDB

Creates a table named Students

Inserts a new student record

Displays a confirmation message in the console

This fulfills the requirements of the final assignment.
